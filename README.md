# Aurora Tape Manager for macOS

Native SwiftUI tape manager using Aurora LTFS 1.5.0 and macFUSE 5.5.0 FSKit.

## Interface
Status, Read, Format, and Write tabs.

## Design
Sequential tape transfers, safe mount/unmount, duplicate handling, and SHA-256 verification.

## Status
Starter SwiftUI v0.1.0 launched successfully on Apple Silicon. Tape integration is the next milestone.
